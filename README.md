# Semantic Crystallization Lab (SCL)

Semantic Crystallization Lab is an EveMissLab research-and-engineering repository for finite semantic crystallization experiments: compressing reusable semantic structure into newly defined lexemes/operators while preserving explicit expansion contracts and measuring dictionary cost, semantic invariants, and compositional reuse.

The first milestone is **SCL v0.1 / EXP-0001 — Finite Semantic Crystallization**.

This repository distinguishes **structural semantic compression** from trivial pointer/address compression. A one-word label is not counted as a substantive result unless its semantic structure can be expanded from explicit definitions and its components/operators demonstrate reuse beyond the single source passage.

Status: initialization.
