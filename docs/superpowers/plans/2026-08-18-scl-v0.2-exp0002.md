# SCL v0.2 / EXP-0002 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use test-first implementation and fresh verification before committing.

**Goal:** Build a reproducible finite neural experiment for bidirectional symbol-feature localization and record it in a bounded 3M matrix ledger.

**Architecture:** A deterministic tiny PyTorch Transformer encoder learns feature prototypes from a small explicit multi-label corpus. Stage-wise curriculum introduces `qevra`, while a frequency-matched pointer control `tivak` isolates mere naming/frequency effects. A matrix-ledger exporter writes symbol-feature and feature-symbol projections, routes, losses and provenance.

**Tech Stack:** Python 3, PyTorch, NumPy, Node.js 20+ for existing SCL tests.

**Spec:** `docs/superpowers/specs/2026-08-18-scl-v0.2-exp0002-design.md`

## Global Constraints

- Never claim ChatGPT/internal foundation-model hidden-state access.
- `qevra` Stage-1/2 examples must not include the original source prose verbatim.
- `tivak` must be frequency-matched to `qevra` within each curriculum stage.
- Use deterministic seeds and record the runtime environment.
- Store source data, generated matrices, metrics and report in GitHub-compatible UTF-8 files.
- Preserve EXP-0001 unchanged.

---

### Task 1: Feature/grid math

Create `python/scl_exp/grid.py` and tests for stable sigmoid feature projection, JS divergence, hidden effective dimension, RMS-relative active coordinates and reverse retrieval.

### Task 2: Corpus and tokenizer

Create explicit feature catalog, curriculum corpus, lexical tokenizer and corpus validation ensuring anti-pointer and no-source-copy gates.

### Task 3: Neural model and stage training

Create deterministic tiny Transformer encoder with learned feature prototypes, sequential Stage 0/1/2 training, and multi-seed evaluation.

### Task 4: 3M exporter

Write the bounded MLF/MMR/MMLC-style matrix ledger, routes, projections, provenance and checksums.

### Task 5: Experiment runner and report

Generate `metrics.json`, per-seed records, Markdown report and update repository documentation.

### Task 6: Verification

Run Python tests, existing Node tests, deterministic experiment rerun, output checksum verification, then package the full repository as a ZIP.
