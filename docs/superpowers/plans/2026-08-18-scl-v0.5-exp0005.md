# SCL v0.5 / EXP-0005 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use test-first implementation and fresh verification before committing.

**Goal:** Build a deterministic 2×2 protocol × persistence SCI continuity experiment with restart and fault injection.

**Architecture:** EXP-0005 consumes canonical EXP-0004 SCI feature packages. `sci_protocol.py` provides typed envelopes and fail-closed batch validation; `persistent_cognition.py` models restartable continuity state; `exp0005.py` executes the four arms and computes preregistered metrics; `three_m_v05.py` exports the continuity ledger and matrices.

**Tech Stack:** Python 3, NumPy, existing SCL JSON/JSONL artifacts; Node.js only for existing regression tests.

**Spec:** `docs/superpowers/specs/2026-08-18-scl-v0.5-exp0005-design.md`

## Global Constraints

- Do not retrain the neural encoder in EXP-0005.
- Cross-agent comparison remains in F01–F19 only.
- No public AI Board write and no live CTCL call.
- No-protocol control is deterministic last-write-wins.
- Protocol path must fail closed on stale, provenance-less, rollback and forked corrections.
- Preserve prior experiment artifacts unchanged.

## Tasks

1. **Typed SCI protocol:** test and implement canonical envelope hash, provenance requirement, stale rejection, idempotence, rollback rejection and fork quarantine.
2. **Persistent cognition snapshot:** test and implement persistent restart versus reset to independent SCI.
3. **Four-arm experiment:** execute A00/A01/A10/A11 with identical bootstrap/fault sequence and measure restart drift, correction retention, target fidelity and consensus.
4. **3M continuity export:** export arm×agent×session×feature matrices, routes, ledger, projection loss and checksums; exclude checksum/verification self-reference.
5. **Runner/report/metadata:** generate deterministic outputs, run full Python/Node suites, rerun EXP-0005 twice, verify prior EXP-0004 canonical hashes, verify 3M and package the release ZIP.
