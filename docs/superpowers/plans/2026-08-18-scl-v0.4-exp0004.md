# SCL v0.4 / EXP-0004 Implementation Plan

**Goal:** Build a deterministic three-agent experiment for SCI reconstruction, transfer, correction, and correlated contamination.

**Architecture:** Reuse independently initialized EXP-0002/0003 checkpoints. Serialize portable sparse feature signatures, update only local symbol embeddings during transfer, record proposal/objection/correction/merge events in an append-only ledger, and export bounded 3M agent-feature/agent-agent projections.

**Tech Stack:** Python 3, PyTorch, NumPy, Node.js 20+ for existing SCL regressions.

**Spec:** `docs/superpowers/specs/2026-08-18-scl-v0.4-exp0004-design.md`

## Global Constraints

- Never compare raw hidden coordinates across independently initialized agents as if axes were aligned.
- Shared cross-agent coordinates are F01–F19 only.
- No source prose or donor hidden vectors inside portable SCI packages.
- Only qevra/tivak embedding rows may move during transfer/alignment.
- Every correction is append-only and provenance-bearing.
- Public AI Board and live CTCL remain untouched in this deterministic experiment.
- Preserve EXP-0001/0002/0003 canonical outputs.

## Tasks

1. SCI package math: sparse construction, hash stability, dense reconstruction, median merge, objections, contamination.
2. Cross-agent transfer: frozen encoder/prototypes, symbol-only embedding update, donor-distance and target-fidelity measurement.
3. AI Board/CTCL compatibility ledger: deterministic IDs, logical instants, event whitelist, hash chaining.
4. Three-agent runner: independent reconstruction, donor transfer, median correction, contamination stress, pointer control.
5. 3M projection: agent-feature, agent-agent, package-feature, routes, provenance, projection loss and checksums.
6. Verification: Python/Node tests, prior-regression tolerance audit, EXP-0004 repeated core hashes, 3M verification, GitHub sync, byte-complete ZIP.
