# SCL v0.1 / EXP-0001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic finite semantic-crystallization harness and the first reproducible experiment, including recursive expansion, invariant verification, dictionary-aware metrics, reusable composite operators, source-paper provenance, and downloadable outputs.

**Architecture:** Use dependency-free Node.js ES modules. Experiment semantics live in JSON artifacts; production code only validates, expands, measures, and reports them. The source prose is never consulted by the expander, which prevents terminal lexemes from acting as hidden prose pointers.

**Tech Stack:** Node.js 20+, built-in `node:test`, JSON, UTF-8 Markdown/text.

**Spec:** `docs/superpowers/specs/2026-08-18-scl-v0.1-exp0001-design.md`

## Global Constraints

- Preserve original uploaded source files byte-for-byte in the downloadable experiment bundle and index their SHA-256 in the repository.
- Canonical generated text is UTF-8; do not Unicode-escape canonical payloads.
- Mathematical source uses `$...$` and `$$...$$` delimiters only.
- Do not use `Omega`/`Ω` as the terminal crystallized lexeme; EXP-0001 uses `qevra`.
- Report surface compression and dictionary-aware cost separately.
- Recursive semantic expansion must not read `source.zh.txt`.
- Use TDD for executable behavior.
