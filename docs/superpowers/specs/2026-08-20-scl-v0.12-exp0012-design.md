# SCL v0.12 / EXP-0012 Design — Autonomy Under Epistemic Pressure

## Goal

Test whether EXP-0011's closed-loop safety can be converted from defer-heavy abstention into same-event epistemic resolution without changing the shared trust history, opponent-mode likelihoods, available probe channels, per-probe cost, or maximum probe count.

## Frozen primary comparison

- **A2-Second-Order** — static second-order reflexive baseline.
- **A3-Closed-Loop-Deferred** — EXP-0011 closed-loop opponent model with at most two probes.
- **A4-Active-Resolution** — same opponent model, same probe set/cost/cap, plus one-step value-of-information planning and probe-conditioned immediate resolution.
- **Oracle** — evaluation ceiling only.

All non-Oracle policies receive the same one-event-delayed trust snapshots. Current event truth is hidden. A3 and A4 both have `max_probes=2` over exactly `independent`, `temporal`, and `provenance`.

## Frozen A4 planner

A4 combines the shared candidate-probability estimate with the current benign/attack opponent posterior, computes dimensionless internal expected losses for `accept`, `reject`, and `defer`, and compares them to each available probe's one-step expected post-probe minimum loss plus a declared probe penalty. It probes only when the expected improvement exceeds a fixed margin. When probes are exhausted, a high attack posterior may resolve to `reject` instead of automatic deferral.

Primary planner constants were frozen before the formal first run:

- internal defer penalty: `0.33`
- internal probe penalty: `0.035`
- minimum probe value margin: `0.012`
- max probes: `2`

These internal utilities are distinct from scored external probe/defer costs.

## Fixture

20 new events across `stationary_resolution`, `mode_switch_resolution`, and `rapid_resolution`, covering benign, boundary-skimming, slow-roll, and false-disagreement modes. Candidate hashes and event IDs must have zero exact reuse from EXP-0001–0011.

## Preregistered hypotheses

- H1: autonomy pack compiles the EXP-0011 result and deferral limitation.
- H2: A4 actually uses active inquiry planning.
- H3: A4 reduces deferral count versus A3.
- H4: A4 risk-weighted target loss is not worse than A3.
- H5: A4 total loss is below A3.
- H6: A4 immediately and correctly resolves at least one event A3 defers.
- H7: a non-Oracle gap remains.
- H8: no exact candidate reuse from prior experiments.

## Exploratory-only follow-up

If the primary planner degenerates, a post-hoc grid may vary only internal defer/probe penalties to diagnose attractor structure. Such a grid is not allowed to modify H1–H8, the frozen A4 arm, or the fixture.

## Non-claims

This is a bounded synthetic feature-space experiment; it does not establish production-calibrated utility values or a universal autonomy law.
