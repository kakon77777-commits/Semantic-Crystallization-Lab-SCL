# SCL v0.5 / EXP-0005 Design — Protocol–Persistent Cognition Continuity

## Goal

Test whether inter-agent protocol structure and intra-agent persistence are independent requirements for maintaining a Symbolic Cognitive Imprint (SCI) across restart, correction, and adversarial message faults.

EXP-0005 does not retrain the neural encoder. It consumes the portable F01–F19 SCI artifacts already established in EXP-0004, so the experiment isolates continuity mechanics above the neural representation layer.

## Factorial design

The experiment is a 2×2 design:

| Arm | Protocol | Persistence |
|---|---|---|
| A00 | no | no |
| A01 | no | yes |
| A10 | yes | no |
| A11 | yes | yes |

Protocol means a typed envelope with schema, symbol, monotonic version, parent hash, package hash, event type, source agent and provenance. Persistence means the accepted SCI state, version, correction history and superseded hashes survive restart.

## Session structure

1. Load three independent qevra SCI states from EXP-0004 seeds 11/23/37.
2. Treat the EXP-0004 coordinate-wise median qevra package as the accepted correction produced at the end of Session 1.
3. Restart every arm.
4. Measure restart drift before any resynchronization.
5. Deliver a valid correction bootstrap.
6. Deliver a fixed fault set: stale version, missing provenance, rollback attempt, and conflicting corrections.
7. Measure final correction retention, target fidelity, cross-agent agreement, accepted/rejected events and rollback/fork behavior.

## Protocol semantics

A protocol-aware receiver must:

- validate package hash and envelope hash;
- require provenance;
- reject stale versions;
- treat exact same-version same-package delivery as idempotent;
- reject same-version different-package conflicts;
- require `parent_sha256` to equal the active package for a forward correction;
- reject explicit rollback to a superseded package;
- detect multiple competing corrections with the same `(symbol, version, parent)` as a fork and quarantine the whole conflict group.

A no-protocol receiver uses deterministic last-write-wins bare-package semantics. This is deliberately unsafe and serves as the control.

## Persistence semantics

A persistent restart restores active qevra SCI package, monotonic version, accepted package hashes, superseded package hashes, and correction-history digest. A non-persistent restart returns to the agent's independent EXP-0004 SCI proposal with an empty continuity history.

## Fault injections

1. `stale_version`: an older donor package arrives after the accepted correction.
2. `missing_provenance`: a package with a forward-looking correction label but no provenance.
3. `rollback`: a newer envelope tries to re-install a superseded donor package.
4. `conflicting_correction`: two different packages claim the same next version and parent.

## Primary metrics

For agent `a`, let `s_a^-` be the Session-1 accepted SCI, `s_a^r` the immediate post-restart SCI, and `s_a^f` the final SCI.

$$
D_{restart}(a)=JS(s_a^-,s_a^r).
$$

$$
R_{corr}=\frac{1}{N}\sum_a \mathbf 1[hash(s_a^f)=hash(s_{accepted})].
$$

Cross-agent final divergence is mean pairwise JS over final qevra feature signatures. Target fidelity is JS to the explicit qevra target feature vector from EXP-0004. The experiment also records false-consensus risk: cross-agent divergence may decrease while target fidelity worsens.

## Preregistered hypotheses

- **H1 Persistence reduces restart drift.**
- **H2 Protocol preserves correction under faults.**
- **H3 Joint protocol+persistence dominates continuity.**
- **H4 Persistence alone is insufficient against semantic overwrite.**
- **H5 Protocol alone can recover after restart but cannot eliminate the restart discontinuity.**
- **H6 Consensus is not a truth signal.**

## Boundaries / non-claims

- No public AI Board writes occur.
- No live CTCL calls occur; logical instants are deterministic compatibility identifiers.
- This is a protocol/persistence experiment over an already-established finite SCI feature space, not a new neural generalization claim.
- F01–F19 is an experiment-specific shared coordinate system, not asserted to exist natively across arbitrary foundation models.
- The accepted median correction is an experimental reference artifact, not a universal truth object.
