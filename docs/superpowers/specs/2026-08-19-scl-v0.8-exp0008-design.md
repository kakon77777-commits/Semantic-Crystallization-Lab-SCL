# SCL v0.8 / EXP-0008 Design — Adaptive Trust Dynamics / Reputation Decay–Recovery

## Question

EXP-0007 showed that history-conditioned source reliability can improve admission relative to static quorums, but it also exposed epistemic hysteresis: new sources are under-trusted and previously reliable sources can retain influence after compromise. EXP-0008 asks whether **the trust memory dynamics themselves** should adapt.

## Controlled comparison

All non-Oracle policies use the same admission support equation, same minimum independent-origin rule, same event sequence, same one-event-delayed feedback, and same F01–F19 SCI coordinate. Only trust-memory dynamics differ:

1. `Cumulative-History` — Beta evidence is never forgotten.
2. `Fixed-Decay` — historical evidence is exponentially discounted at a constant rate.
3. `Adaptive-Dynamics` — evidence decay depends on learned volatility; negative feedback to a high-reputation root receives a betrayal boost, while positive feedback to a low-reputation root receives a recovery boost.
4. `Oracle` — evaluation ceiling that sees the synthetic truth label; never used as a deployable policy.

## Anti-leakage boundary

For event $t$, all non-Oracle policies decide without access to whether event $t$ is genuine or pollution. At the start of event $t+1$, the synthetic validation outcome of event $t$ may update trust. Thus feedback is exactly one event delayed.

## Benchmark phases

The 20-event sequence contains:

- calibration of long-lived A/B/C reputation;
- D/E cold-start as genuinely useful new sources;
- repeated B/C betrayal;
- B rehabilitation with D/E;
- later concept/provenance drift where A degrades and F/G emerge.

## Primary metrics

- plasticity / false-reject rate;
- integrity / false-accept rate;
- risk-weighted cumulative target JS;
- cold-start false rejects and first-accept lag;
- betrayal pollution accepts;
- recovery false rejects and first-accept lag;
- concept-drift attack accepts and genuine rejects;
- delayed-feedback Brier calibration;
- root trust mean and volatility trajectories.

## Preregistered hypotheses

- H1: no-forgetting cumulative trust exhibits reputation hysteresis.
- H2: fixed decay reduces betrayal hysteresis relative to cumulative history.
- H3: adaptive dynamics records betrayal/recovery as state-dependent trust volatility and eventual rehabilitation.
- H4: adaptive dynamics lowers risk-weighted loss relative to cumulative history.
- H5: adaptive dynamics remains below the Oracle ceiling.
- H6: cold-start and betrayal cannot both be eliminated at zero cost in this fixture.
- H7: adaptive trust learning rate is state-dependent rather than constant.

Any post-run observations must be labeled exploratory and must not replace these preregistered decisions.

## Non-claims

This is a deterministic synthetic online benchmark over a previously constructed SCI coordinate. It does not establish real-world source truth, production-optimal decay constants, universal Bayesian cognition, or arbitrary-model hidden-space alignment.
