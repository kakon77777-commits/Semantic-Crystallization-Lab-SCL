# SCL v0.2 / EXP-0002 Design — Bidirectional Symbol–Feature Localization

## Goal

Test a bounded version of the SCL hypothesis on a transparent neural model: after a newly invented lexeme is assigned progressively richer compositional semantics, can one surface token localize a broader learned feature bundle while remaining close to the feature signature of the longer source passage?

This experiment does **not** read hidden states from ChatGPT or any proprietary model. The primary AI-side evidence comes from a small deterministic PyTorch encoder trained from scratch on an explicit finite corpus. Therefore the result is a mechanism demonstration, not evidence about arbitrary foundation models.

## Experimental object

EXP-0001 supplied the crystallization chain:

$$
T_0 \rightarrow T_1 \rightarrow T_2 \rightarrow T_3 \rightarrow \texttt{qevra}.
$$

EXP-0002 keeps the same terminal lexeme and asks whether learned AI representations can acquire its compositional meaning.

The AI model exposes a hidden state:

$$
h(x) \in \mathbb{R}^{d}
$$

The encoder uses masked-mean pooling over attended non-padding token states (rather than a learned CLS-only bottleneck) for stability on this small from-scratch corpus, and a learned feature-prototype matrix:

$$
F \in \mathbb{R}^{m \times d}.
$$

Symbol-to-feature scores are:

$$
A_{S\to F}(x,j)=\sigma\left(\frac{h(x)\cdot F_j}{\sqrt d}+b_j\right).
$$

The reverse feature-to-symbol projection ranks candidate symbols using the weighted feature bundle against their hidden states.

## Curriculum

For each seed, Stage 0 trains on bounded source paragraphs, controlled paraphrases, feature anchors, and the lower-order lexemes. The complete source passage is reserved for evaluation so repeated long-sequence attention does not dominate the CPU experiment.

1. **Stage 0 — unknown**: the tokenizer contains `qevra`, but no training example assigns meaning to it.
2. **Stage 1 — compositional definition**: `qevra` appears only through its explicit composition from lower-order SCL lexemes/operators; direct source-prose copying is forbidden.
3. **Stage 2 — contextual reuse**: add novel contexts that use `qevra` without reproducing the source passage.

The control lexeme `tivak` is frequency-matched but receives only document-pointer semantics. It is the anti-pointer control.

## Measured quantities

Human/source-side target features are explicit and auditable. AI-side measurements are learned from the model.

For expression $x$:

- feature support size at threshold $\tau$;
- target feature precision, recall and $F_1$;
- cosine similarity $\cos(h(x),h(T_0))$;
- Jensen–Shannon divergence between normalized feature signatures;
- hidden-state effective dimension from spectral entropy;
- hidden active-coordinate count under a fixed RMS-relative threshold;
- reverse feature-to-symbol retrieval rank;
- symbol $\to$ feature $\to$ symbol round-trip success.

The hypothesis is supported in this bounded model if `qevra` gains feature coverage and source localization from Stage 0 to Stage 2 while `tivak` does not. A monotonic increase in raw hidden active coordinates is **not** required; that is separately measured because dense neural codes may broaden semantically without activating more coordinates under a naive threshold.

## 3M bounded profile

EXP-0002 records results in a bounded 3M profile:

- **MLF role**: coordinates, matrix cells, provenance and explicit projection-loss reports;
- **MMR role**: both row-wise symbol-to-feature and column-wise feature-to-symbol traversal;
- **MMLC role**: deterministic projection, distortion and round-trip calculations.

The directory shape follows the public MLF matrix-ledger layout where practical, but EXP-0002 does not claim formal MLF 1.0 conformance because the official MLF compiler is not executed in this environment.

## Controls and non-claims

- no proprietary-model hidden states are claimed;
- no result is generalized from the toy model to all LLMs;
- training frequency is controlled with `tivak`;
- `qevra` training data cannot contain the full original source passage;
- all seeds, corpus rows, model dimensions, thresholds and outputs are committed;
- the experiment may refute the naive "more meaning = more active hidden coordinates" version while supporting feature-localization growth.
