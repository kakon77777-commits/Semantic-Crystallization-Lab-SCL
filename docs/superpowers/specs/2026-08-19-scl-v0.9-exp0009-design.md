# SCL v0.9 EXP-0009 Design — Uncertainty-Aware Epistemic Decision

**Goal:** test whether richer belief-state variables and a multi-action decision space improve SCI admission when trust memory is held fixed.

## Controlled comparison

All non-Oracle arms consume identical event-by-event trust snapshots. The independent variable is decision projection only.

- Scalar-Threshold: mean-only binary accept/reject.
- Posterior-Mean: mean-only accept/reject/seek/defer.
- Belief-State: posterior mean + Beta uncertainty + volatility + disagreement with the same four actions.
- Oracle: truth-visible evaluation ceiling only.

## Costs and timing

Target distortion is risk weighted. Evidence queries and deferral have explicit additive costs. Defer resolves one event later using validation, not current truth.

## Failure injections

The 12-event online fixture contains minority novelty, historically trusted coalition betrayal, structured disagreement, correlated echo, high-risk genuine/pollution cases, new-source splits, and an intentionally unresolved low-risk event.

## Non-claims

The belief aggregation and costs are transparent bounded fixtures, not production-optimal epistemology. The experiment tests mechanism separation, not universal policy optimality.
