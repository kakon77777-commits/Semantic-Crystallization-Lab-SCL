# SCL v0.10 / EXP-0010 — Reflexive Epistemic Challenge / X-Order Cognitive Lift

## Goal

Test whether the *published experiment chain itself* can become a later cognition-shaping artifact, while separating genuine meta-strategy transfer from direct benchmark memorization.

## Experimental factor

All non-Oracle policies receive the same SCI feature coordinate, the same trust snapshots, the same event stream and the same delayed audit feedback. They differ only in reflexive access/order:

- **A0-Reactive (order 0)** — EXP-0009 Belief-State policy; does not read EXP-0001–0009 artifacts.
- **A1-Artifact-Reflexive (order 1)** — compiles a deterministic rule pack from EXP-0001–0009 reports plus EXP-0004–0009 validation outcomes; can prospectively challenge a high-confidence accept.
- **A2-Second-Order (order 2)** — includes A1 and additionally models how an adversary can target the published A1 challenge rule through boundary skimming / repeated slow-roll structure.
- **Oracle** — truth-aware evaluation ceiling only.

## Artifact compiler

`compile_reflexive_rule_pack()` must read real checked-in artifacts and record their SHA-256 values. The current rule pack extracts only claims explicitly supported by prior validation results:

1. false consensus / donor-bias warning;
2. structural validity is not semantic admissibility;
3. static quorum plasticity–integrity tradeoff;
4. high-reputation source betrayal can bypass learned trust before feedback;
5. better trust-state calibration need not improve decisions;
6. reactive uncertainty/evidence seeking may arrive too late.

Current EXP-0010 fixture truth is never provided to the compiler.

## Phase I — novel transfer

Use newly instantiated candidate packages and event IDs that are not copied from earlier experiments. Events are homologous to prior failure *classes* (trusted consensus pollution, minority novelty, correlated echo, structured split, reputation rebound) but use new provenance roots, feature perturbations and package hashes.

Primary question:

$$
L_{A1}^{\text{novel}} < L_{A0}^{\text{novel}}\ ?
$$

## Phase II — meta-adversarial reflection

The environment is explicitly conditioned on the published A1 challenge rule. It introduces boundary-skimming, slow-roll and false-disagreement patterns intended to fall below or distort A1's prospective challenge trigger.

A2 receives observable meta-context only:

- positive-coalition signature;
- repeated-coalition streak;
- cumulative candidate drift from the last externally validated anchor;
- A1 challenge score / threshold relationship.

Current truth remains hidden.

Primary question:

$$
L_{A2}^{\text{meta}} < L_{A1}^{\text{meta}}\ ?
$$

## Memorization guard

Before evaluation, scan EXP-0001–0009 text artifacts for every 64-hex token. Every EXP-0010 candidate package SHA must have zero exact overlap. Every EXP-0010 event ID must be absent from the prior experiment corpus.

This guard rules out exact artifact replay; it does **not** claim structural independence, because Phase I intentionally tests homologous failure classes.

## Costs and actions

Use the existing EXP-0009 action/cost contract:

- `Accept`
- `Reject`
- `Seek Evidence` (fixed per-query cost)
- `Defer` (fixed risk-scaled delay cost)

Deferred candidates are resolved under one-event-delayed validation.

## Pre-registered hypotheses

- **H1** — artifact pack compiles the prior failure chain.
- **H2** — A1 reduces Phase-I novel-transfer loss vs A0.
- **H3** — A1 catches at least one A0 high-confidence error on a new event.
- **H4** — the Phase-II meta-adversary exploits the published A1 rule at least once.
- **H5** — A2 reduces Phase-II loss vs A1.
- **H6** — no exact candidate hash/event-ID reuse from prior experiments.
- **H7** — A2 remains worse than Oracle.

Negative outcomes are retained unchanged.

## Boundaries / non-claims

- Deterministic transparent mechanism experiment; no frontier-model hidden-state claim.
- No claim that the artifact compiler equals semantic paper-reading by a future AI.
- No claim that higher-order cognition monotonically improves performance.
- No public AI Board write, live CTCL call or neural retraining.
