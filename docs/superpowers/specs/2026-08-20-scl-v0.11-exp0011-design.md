# SCL v0.11 / EXP-0011 Design — Closed-Loop Reflexive Strategy

## Goal
Test whether a persistent opponent-response model can outperform the static second-order reflexive trigger from EXP-0010 by selecting evidence probes through a model→act→observe→update loop.

## Frozen factors
- Same EXP-0010-derived artifact chain and shared delayed-feedback trust snapshots for all non-Oracle policies.
- Same three probe channels and same per-probe/defer costs.
- Current event truth hidden from all non-Oracle policies.
- New 19-event fixture with zero exact candidate-hash reuse from EXP-0001–0010.
- A3 updates opponent posterior only from probe responses; no truth label enters the opponent model.

## Policies
- A0-Reactive
- A1-Artifact-Reflexive
- A2-Second-Order
- A3-Closed-Loop
- Oracle ceiling

## Pre-registered hypotheses
H1 closed-loop pack compiles EXP-0010; H2 A3 uses multiple probe types; H3 A3 reduces mode-switch loss vs A2; H4 A3 catches at least one A2 error; H5 A3 tracks multiple attack modes; H6 switch lag/non-Oracle gap remains; H7 no exact candidate reuse.

## Non-claims
The four-mode likelihood table is a deterministic test fixture, not a real-world adversary model. Deferral is explicitly costed but remains a strong capability assumption.
