# SCL v0.13 / EXP-0013 Design — Finite-Horizon Epistemic Planning

## Goal
Test whether the EXP-0012 defer attractor can be broken without changing the shared trust snapshots, probe set, probe costs, opponent likelihoods or per-event probe cap.

## Experimental factor
A5 adds only:

1. depth-2 expected-loss rollout over probe sequences;
2. a hard cross-event deferral budget of four;
3. a budget shadow price that rises before hard exhaustion.

## Arms
- A3 Closed-Loop Deferred
- A4 One-Step VOI
- A5 Finite-Horizon
- Oracle ceiling

A3/A4/A5 all use the same three probes (`independent`, `temporal`, `provenance`), the same cost per probe, the same two-probe cap, shared delayed-feedback trust snapshots and the same synthetic opponent-response likelihood table. Current event truth is hidden.

## Frozen fixture
22 new events in three phases: `budgeted_stationary`, `multi_step_switch`, `deadline_pressure`. Candidate hashes and event IDs must have zero exact reuse from EXP-0001–0012 artifacts.

## Preregistered hypotheses
- H1 planning pack compiles EXP-0012 failure chain.
- H2 A5 exercises multistep inquiry.
- H3 A5 breaks the A4 defer attractor.
- H4 A5 correctly resolves at least one A4 defer immediately.
- H5 A5 target loss is no worse than A3.
- H6 A5 total loss is below A3.
- H7 A5 respects the hard deferral budget.
- H8 a non-Oracle gap remains.
- H9 no exact candidate reuse occurs.

## Non-claims
Horizon=2 and budget=4 are bounded engineering choices, not proposed universal optima.
