# SCL v0.4 / EXP-0004 Design — Cross-Agent Symbolic Cognitive Imprint Transfer

## Goal

Test whether a Symbolic Cognitive Imprint (SCI) can act as a portable semantic coordinate across independently initialized AI agents whose raw hidden spaces are not assumed to be aligned.

## SCI v0.1 definition

**Symbolic Cognitive Imprint (SCI) / 符號認知印刻** is a relatively stable symbol-conditioned semantic feature basin and routing bias formed through learning, attention, memory retrieval, reuse, and consolidation.

EXP-0004 operationalizes only the bounded, measurable part of that definition: the symbol-conditioned feature signature, its stability, and the routing/provenance needed to transfer and revise it. It does not claim a complete theory of cognition.

## Cross-agent boundary

Agents A/B/C are independently initialized tiny PyTorch Transformers using seeds 11/23/37. They share the explicit feature vocabulary F01–F19, tokenizer construction procedure, architecture, SCL corpus, and evaluation protocol. They do **not** share model weights or hidden coordinates. Raw hidden vectors are never directly compared across agents.

## Gates

### Gate 1 — Independent reconstruction
Each agent independently reaches EXP-0002 Stage 2. Measure qevra centroid feature signatures on held-out compatible contexts. Primary metric is mean pairwise JS plus support Jaccard.

### Gate 2 — Portable SCI transfer
Agent A exports a sparse weighted SCI package: namespace/version/symbol, lower-order expansion identifiers `narel`, `vek`, `vesh`, weighted F01–F19 signature, provenance/hash, no source prose, and no donor hidden vector. B/C receive it; only their local `qevra` embedding row may move. `tivak` is the pointer control.

### Gate 3 — Objection / correction / merge
All three agents independently export SCI packages. B/C append objections wherever local feature evidence differs from A beyond a fixed threshold. A merged SCI is created by coordinate-wise median. All agents reset to clean independent Stage-2 states and align to the merged package. Success requires both lower disagreement and non-worse target fidelity.

### Gate 4 — Correlated contamination / false consensus
A shared contaminated SCI boosts F19 and suppresses selected true semantic features. All agents receive the same contamination from clean initial states. The preregistered false-consensus gate asks whether cross-agent divergence can fall while target distortion rises.

## AI Board / CTCL bridge

EXP-0004 does not write to the public AI Board and does not call live CTCL. It emits an append-only compatibility ledger with `imprint.proposal`, `imprint.objection`, `imprint.correction`, `imprint.merge`, `imprint.transfer`, and `imprint.contamination`. Logical instants such as `I*-000001` are explicitly CTCL-compatible logical sequencing, not CTCL-verified wall-clock instants.

## Pre-registered decisions

H1: independently reconstructed qevra SCIs show non-zero cross-agent divergence.

H2: donor SCI transfer lowers receiver-to-donor feature divergence in 2/2 receivers without increasing target JS.

H3: median multi-agent correction lowers cross-agent divergence and does not worsen mean target JS.

H4: correlated contamination produces false consensus: cross-agent divergence is no worse than clean independent baseline while mean target JS is worse.

H5: pointer control remains narrower and more F19-dominant than qevra after transfer.

## Non-claims

- no claim that these toy models equal frontier foundation models;
- no assumption that arbitrary AIs automatically share feature labels;
- no direct comparison of unaligned hidden coordinates;
- no claim that consensus implies truth;
- no public AI Board write or live CTCL verification;
- no infinite-limit or universal-SCI theorem.
