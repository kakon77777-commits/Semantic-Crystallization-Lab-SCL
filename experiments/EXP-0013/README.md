# EXP-0013 — Finite-Horizon Epistemic Planning / Deferral-Budgeted Inquiry

This bounded experiment tests whether multi-step probe planning plus a hard deferral budget can break the EXP-0012 abstention attractor.

Formal result: A5 uses 22 probes, defers 4/22 events, reaches 81.8% immediate resolution and total loss 0.02663. All nine preregistered gates pass. The remaining failure mode is over-rejection: 0 false accepts but 4 false rejects.
