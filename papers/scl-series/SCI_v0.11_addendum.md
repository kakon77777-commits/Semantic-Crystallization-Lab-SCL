# SCI v0.11 Addendum — Closed-loop Reflexive Strategy

EXP-0011 adds the bounded mechanism

$$
\text{meta-model}\rightarrow\text{choose probe/action}\rightarrow\text{observe response}\rightarrow\text{update meta-model}.
$$

The result distinguishes static reflexive order from operational closed-loop reflexivity. In the deterministic fixture, a response-conditioned opponent posterior changes probe selection and sharply reduces loss relative to the static second-order trigger, but primarily by increasing probe use and deferral. This is a finite mechanism result, not a universal adversary model or monotonic higher-order cognition theorem.
